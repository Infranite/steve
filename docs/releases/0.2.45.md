# Steve v0.2.45

- **在对话里可以直接新建 Bot。** 比如说“加一个验收 Bot，专门复核开发的交付”，Steve 会起草一张「新建 Bot」卡片，列出名字、职责、工作规范和权限；点「应用」才创建，「撤销」会删掉这个 Bot，它期间接的未完成事项转交给 Steve。名字和已有 Bot 重复时不新建，提示直接改那个 Bot。
- 一句话最多可以改 6 处设置（原来是 3 处），一次就能调整整套 Bot 分工。
- Steve 提出设置或 Bot 调整的建议后，回一句“按这个方案改”，Steve 会按它的建议起草卡片，不再把这句话建成开发事项。
- 新增 `ops/bot-roles-report.py`：对比某件事项前后各 N 件事项的执行 Bot、补充说明、打回和重开次数，以及从交付到完成的时间，用来评估分工调整的效果。
