# Steve v0.2.82

Steve 不再替 Worker 做额外的限制：

- 事项会话的回合不再有 6 小时上限，等你处理审批卡的时间也不会让回合超时。回合由 agent 自己结束，或者由你停止。
- Bot 的权限模式新增“不再询问”（`bypassPermissions`）。设成这个模式的 Bot 会按设置运行，不再被降成“每次都问你”。边界交给系统沙箱，以及 YOLO 原有的硬限制。
- 默认验收方式改为自动验收：交付就算完成，没通过的检查和没做完的步骤会写在交付卡和时间线上，你随时可以打回。没有改过这项设置的工作区会随之改为自动验收；已经明确设成“需要你验收”的工作区、Bot 和事项不受影响。
- Agent 结束回合时，如果没有交付、也没有提问，Steve 不再直接出“它停下了”的卡片，而是先提醒它：上下文压缩后 Steve 的工具仍然可用；已经完成就用 `steve_deliver` 交付，需要你决定的事用 `steve_ask` 提出来。只写在回复里的汇报和方案也会先提醒，不再直接变成卡片。
- 验收通过后，如果 Agent 没有请求发布，事项按验收直接完成，不再出“还要发布吗”的卡片。配了完成规则（合并，或合并并打 tag）的项目不受影响，仍按规则核对远端。
