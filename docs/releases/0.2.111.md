# Steve v0.2.111

普通会话和一次性调用的实时采样与原生结束用量使用同一回合计量身份，避免重复结算。保留原始 cache creation 的明确零值与正数，缓存和 reasoning 不再混入其他消费字段。

Claude 可从实际配置目录的 transcript 补采运行中及错误、取消前已持久的用量，按 message ID 去重并区分模型和主子链；合成零不会抹掉已观察到的消费。shutdown 会停止并等待采样协程，慢来源读取有界等待；这不会自动回写历史统计。

Node homes can reopen after shutdown even when a concurrent command temporarily inherits the lock descriptor before exec. Adapter exit now cancels and joins timed-out stdout readers, stderr readers and stdin writers; session shutdown waits for their bounded cleanup instead of leaving detached transport tasks.

会话、事项和统计页现在共用持久用量账本。运行中已上报的增量即时入账，累计快照和最终结算替换此前累计；取消、Hub 重启、报告重放和重复结束不会再次追加同一笔用量。

用量区分尚未上报、不可用、部分覆盖与真实零值，API 返回字段级覆盖信息。一次性调用保留明确上报的零值，并复用同一报告合并规则。账单累计不用于推算实时 TPS。

已有用量可通过统计重建恢复汇总；从未采到或来源已丢失的历史用量仍显示未知。公开合同和恢复限制见部署说明。

普通会话与一次性调用现在实际使用同一归并器，按 epoch、模型和字段选择 All/Main，保留默认模型及 adapter canonical 名称的覆盖关系；Background 不计入当前调用。修复部分字段漏计与仅上下文 Final 提前封口，保留费用异常、迟到、重试零消费和调用归属证据。历史 Main 费用伴随行有可靠归属时不再误报缺失，仅同毫秒候选明确标为历史费用归属不确定，真正 cost-only 缺失仍保留。

One-shot Think and research calls now persist usage during execution with stable call and retry ownership. Dropped waiters, timeouts and Hub restarts retain their bills; late final reports update the original consumption while preserving the failed result. Local and Node paths use the same reducer and projection, without extra rows for zero-consumption retries.

Local one-shot reports and caller outcomes also survive a temporarily failed statistics projection and are retried after recovery, without keeping the original waiting future alive.

Research 与 Think 在取消或预算、策略停止后，先停止执行，再等待有界源补采，将停止前已持久但尚未轮询的尾部用量结算到原 Job，之后才确认结束。Final 重放不重复计费，调用失败状态保持；源失联仍保留已知下限与不可用诊断，补采不注入实时 TPS。

Node 关闭时会等待普通会话的采样器、RPC 延续和重试/清理定时任务退出，避免后台任务拖尾。

调用结果投影恢复现在使用持久 FIFO，每轮仍最多128项；失败项在尝试前轮换到队尾，避免阻塞后续健康调用。finish/cancel 共用公平规则，投影回滚、Hub 重启和持续新请求不会重置轮换进度；没有新 Usage 时也会继续恢复。启动先持久化中断调用的失败结果，投影故障记录后交周期 worker 重试；晚 Final 仍更新原账单，不将失败改成成功。

Session and one-shot harness calls now share attempt-level token collection and final settlement on success, cancellation and error. Codex rollout usage is sampled during execution from the adapter’s configured home and reread for late tail writes; duplicate events, counter resets and concurrent sessions are isolated. One-shot usage is recorded while running so cancellation keeps its audit trail.

Native codex-acp 2.x cache and reasoning fields are normalized consistently with quota reports. Context occupancy remains separate from consumed tokens, absent fields remain unknown, and replayed reports retain stable identities. Historical usage is not rewritten automatically; recovery needs retained reports or attributable source counters.

一次性模型调用统一处理运行中累计用量、结束结算与报告重放，避免重复计费。不同模型和计量周期分别合并，主循环与总用量不再重复相加，后台用量不计入当前调用；仅含费用或上下文的报告也不会抹掉已采集的 token。

统计记录保留真实上报的零值，缺失用量保持未知。失败、取消及重试前已消耗的用量仍会记录；零消费重试保留诊断明细，不增加请求计数。
