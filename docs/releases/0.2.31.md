# Steve v0.2.31

- **A project's page shows how its repository merges and releases.** Under "合并通道": the target it merges into, whether changes go through the host's merge queue, a pull request or a push, what has to pass before merging, how a merge becomes a release, which files every change collides on (versions, release notes, migration numbers, lock files) and how they are settled, and the last seven days' pace. Each line says where it came from; when the host can't be read it says so instead of guessing "none". Read only for now: batching on top of it comes next.

- When Steve isn't sure a new request belongs to an open item, it no longer just asks "这是给 ST-n 的吗？" with "送到 ST-n / 在这里回答". It now says what the request shares with that item (the same page, module or goal), recommends appending it, and offers "追加到 ST-n" (highlighted) or "单独建项". An item made this way goes to the same project and bot as the item it was close to. Older cards keep working.
- A message that names the item itself ("追加到 ST-40：…", "给 st40 加上…") is appended right away, without asking again.
