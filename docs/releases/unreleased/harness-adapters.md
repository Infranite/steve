- 可以接入自己的 ACP harness：在 Node 的 `harness.json`（Hub 自带的 Node 读 `$STEVE_HOME/harness.json`，或 `STEVE_HARNESS_MANIFEST` 指定的文件）的 `adapters` 里写 `{"my-agent": {"command": "/path/to/agent", "name": "My Agent"}}`，可选 `args`、`env` 和 `properties`（例如 `modes` 把 Steve 的权限模式对应到它自己的模式 id，`nested_sandbox`、`self_read_only` 说明它的沙箱）。只要它支持 ACP，就能用来跑会话。旧的写法（`{"claude-code": "/path"}`）照常可用；清单读不出来时只记一条警告，不会阻止启动。
- Node 会用 ACP 的 `initialize` 询问自己接入的适配器（每五分钟最多一次），报告它的名称、版本、是否支持图片、恢复会话、列出会话以及登录方式；启动不了或没有响应的适配器会标明原因，不影响其他功能。内置的 Claude Code 和 Codex 仍按原来的方式检测，不会为此额外启动适配器。
- Claude Code 和 Codex 之间的差别（权限模式的对应、Codex 的模型目录参数、只给 Claude Code 的 `CLAUDE_CODE_EXECUTABLE` 和会话设置）改为内置适配器的声明数据，行为不变。
