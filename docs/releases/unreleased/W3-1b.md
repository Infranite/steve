Needs a minor release: the ordinary Hub–Node protocol changes from 10 to 11.

Upgrade the Hub and its Nodes together. A Node with a different ordinary protocol can use the permanent upgrade protocol, but cannot run ordinary work until it has a compatible release.

Node RPC failures now use the shared error contract: retry advice is an object with a kind, operation/state diagnostics are in params, and concrete reasons distinguish a missing operation, a lost snapshot and a refused downgrade. Former offline, denied and expired codes become unavailable, forbidden and stale. Unknown outcomes default to no automatic retry; the transport paths proven safe to resend retain the same operation ID and the Node deduplicates them.
