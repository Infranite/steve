Marking an item finished closes its current cycle immediately, even when the item is paused, waiting on a prerequisite, or still running. Session stop and workspace cleanup follow after the completion is recorded.

The item view carries its lifecycle state, cycle, revision, and delivery references. A GitHub-connected owner can declare a set of required pull requests with `PUT /api/github/items/{id}/delivery`, supplying `cycle`, `revision`, and the `pulls` array of linked GitHub pull-request IDs. Automatic completion with declared pull requests waits for every accepted range to be present on its repository's current default branch. A change that was reverted or cannot be verified leaves the item open.
