- 新增“外部渠道”接入：Steve 可以通过一个独立运行的渠道服务（WebSocket 协议）接入内置适配器之外的即时通讯系统。在 **接入 · 外部渠道** 填写渠道服务地址（`wss://`，明文 `ws://` 只允许本机 127.0.0.1 或 ::1）、渠道服务发给这个 Hub 的访问令牌，自签名证书再填证书指纹即可。Hub 主动连出去，不开放端口；渠道服务崩溃或重启只会让这个渠道暂停，Hub 不受影响，恢复后从上次的位置续接，断开期间可能漏掉的消息会补取回来（只记录，不处理）。
- 外部渠道以你本人的身份工作：收到的消息走和其他渠道一样的规则；接入前的旧消息、补取回来的消息和你自己发的消息只记录；以你的名义回复、表情回应和撤回都经过渠道服务，渠道服务禁止发送时连接变为只读。
- 协议文档、一致性清单和测试向量随代码发布（`steve_channels::adapters::ext_ws::protocol`），测试套件里带一个按协议实现的假渠道服务。
