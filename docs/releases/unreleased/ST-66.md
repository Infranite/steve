统计页“现在”区域新增输出 TPS、输出会话数和近 60 秒趋势，每秒通过 `GET /api/stats/realtime` 更新，只跟随项目与 Bot 筛选，不受历史日期范围影响。TPS 为最近 10 秒输出 token 数除以 10；输出会话数为该窗口有输出的唯一会话数。页面支持中英文、窄屏、键盘查看和趋势明细。

实时数据区分实测、文本估算、无输出、不可用和部分覆盖。当前全部注册 harness（含 Pi）在未验证定时输出 token 契约前仅使用可见输出文本估算，不将累计 usage、结束账单或上下文 token 当作实时输出。趋势缺失点保留断线，覆盖不完整时 TPS 和会话总量均待确认，不用局部观察值替代未知总量。说明分别区分 3 秒采集新鲜度与 5 秒接口响应陈旧；接口缺失、网络异常、响应不兼容或陈旧数据不显示为实时零值。

采集记录持久保存并可回读，重放去重、迟到事件和异常停止时间不会制造输出尖峰或抹去近期输出。升级时依据已持久的 Node 停止事件及匹配终止回执恢复有界未知区间，已确认停止及未发出的取消不永久污染当前统计；缺乏可信停止证据时仍保守保留未知。滑窗查询使用带索引的时间边界，采样与文本偏移按会话及执行保留策略保存。
