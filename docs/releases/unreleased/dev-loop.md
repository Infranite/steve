- For contributors: `python3 ops/dev.py` runs a checkout as a development Hub next to the installed one, with the web dev server in front, so a change can be tried in seconds without CI or a release. `up --fresh` starts from an empty database; `up --snapshot` from a copy of the installed Hub's data that shows it without acting on it (nothing resumes, no Node, vault locked). `restart` rebuilds the Hub incrementally. See CONTRIBUTING.md.
