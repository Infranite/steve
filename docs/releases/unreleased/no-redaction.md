- Steve no longer masks, filters or refuses content. What you type is stored and routed as typed: the paste guard that replaced passwords, tokens and keys in your messages, queued edits and config drafts is gone. What a model or a command says reaches you and the agent as it is: there is no more redaction of session records, tool results, harness stderr, secret-use and Node command output, git push output, CI logs, GitHub comments and pull requests, knowledge, flow steps or delivered reports. Channel replies, mail and GitHub pushes are no longer held back for containing a secret, and the disclosure check no longer treats a secret value as a leak (it still checks knowledge levels and audiences). A secret-use command with a token written into it now runs. Vault items, their encryption, approvals and grants are unchanged; a model that repeats a secret is a reason to switch harness or model.
