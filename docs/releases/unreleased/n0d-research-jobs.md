- 开启本机 Node（`STEVE_NODE_MODE=local`）后，`STEVE_NODE_JOBS` 里再写上 `research`（例如 `STEVE_NODE_JOBS=think,research`），就地研究会作为 Node 任务运行，每个模型一次。按 设置 · 模型 选模型和依次回退、跟进时接着上一轮的会话、边写边显示的草稿和工具行、停止按钮、附件和图片、预算、越界即停和审计记录、统计里的研究用量都和原来一样；一个工作空间同时只跑一个研究、同时最多几个研究的限制和提示也照旧。研究里 Steve 的只读工具（知识库、事项、会话列表）经由 Node 调用，只对这次研究、只在研究进行中可用。设置里没有限定研究时长时，在 Node 上也不限时，和原来一样不会中途被截断。研究的目录不在本机 Node 管理的目录下（或读不到这些目录）时，这次研究仍在 Hub 里运行，并记入 `/healthz` 的 `research_fallbacks`。不设置时一切照旧。
