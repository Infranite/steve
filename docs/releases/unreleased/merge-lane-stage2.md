- Merge lanes (stage 2). For a project whose completion rule is "merged" or "merged and tagged", an agent's request to release no longer opens a release card per item. The item goes into the merge lane of its target (the repository and branch). Alone, it merges straight away. When others for the same target come in while one is merging, they form one batch: it collects for up to 2 hours from its first request or 10 requests, merges once, runs the lane's checks once and releases once, and the release of the one already merging waits for it. You get one card per batch. A member that conflicts with the ones before it leaves the batch with the conflicting files named, and the others go on. Each item's timeline says where it is in the lane.
