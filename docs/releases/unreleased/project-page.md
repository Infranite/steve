- A project's page has two tabs, Overview and Settings, and the overview shows the most important things first:
  - **Items** lists the open items, with the ones waiting on you first, then the ones that failed or are stuck, then the ones still running. The latest finished items fill the list up to six. Any merge batch in progress, with "Merge and release now", sits under the items. When the project has no items, this is a single line.
  - **Last 7 days** shows items done, changes merged and versions released (for a git project), failures by kind, estimated cost, Agent time and the time items waited on you. "Open in statistics" opens the statistics page filtered to this project.
  - **Repository and delivery** is one card with one line each for the folder and machine, the repository and branch, the linked GitHub repository, how changes merge and how they are released. Under it, folded away, **Repository conventions** lists what Steve found in the repository once each: the checks before merging, the numbers and files that need coordinating when merging (version tags, release notes, migrations, lock files), and how Steve found these.
- Settings holds the "tell Steve" field, the name and description, the default Bot, branch-per-item, YOLO and done-when options, the merge lane's batch window (or the merge queue's settings), and linking the GitHub repository.
- The project's description now appears under its name. The "last 30 days" line in the page header is gone; the Last 7 days figures replace it.
