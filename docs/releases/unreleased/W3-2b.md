Needs a minor release: the Node journal moves to schema v4, which drops all earlier command, process and grant records and cannot be opened by an older Node.
Upgrading a Node deletes every command, process and grant record it kept from before the upgrade. Commands issued before the upgrade are refused afterwards (judged by the Node's clock, so a Hub whose clock runs ahead may see recent commands refused once); reading the output of an attempt that ran before the upgrade fails. Stop the old Node and its sessions before upgrading: the new Node no longer knows about processes the old one started. Once the new Node has opened its journal there is no way back to the previous version.
