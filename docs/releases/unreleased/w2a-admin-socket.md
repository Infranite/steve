Management commands (`steve-hub --access …`, including commands run by `steve setup`) use the running Hub through a private local Unix socket. Listing tokens and clients no longer reopens the database or competes with the Hub for a migration write lock. If the Hub is running or upgrading but its management socket is unavailable, the command reports the socket path and exits without reopening the database. When the Hub is stopped, commands retain their existing direct database access for now. Command output and exit codes are unchanged.
