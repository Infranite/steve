- 开启本机 Node（`STEVE_NODE_MODE=local`）后，之前由旧运行器跑的会话会在空闲时转到 Node 上：下一条消息到来（或排队的消息发出）时，旧运行器闲着的 agent 进程先退出（确认整个进程组都已退出后才转），会话在 Node 上用原来的 harness 会话 id 接着原来的对话继续，并在会话里提示一次“已转到 Node 上运行”。正在跑的一轮、待恢复的中断、未答复的授权卡片都会先在旧运行器上走完，之后再转，从不在一轮中途切换。
- 无法转到 Node 的旧会话（工作目录已不存在、项目已归档、Bot 已停用或删除、Node 不支持的权限模式、导入的只读会话等）会在空闲时结束，并在会话里写明原因，只写一次。这样结束的会话不会再恢复：直接给它发消息会被拒绝，在事项里发消息会开始新会话。工作目录已不存在的会话里排队的消息再也发不出去，会随会话一起撤下，并在会话里列出。
- `/healthz` 的 `node` 一栏新增 `adopted` 和 `retired`：本次启动以来转到 Node 的旧会话数和因无法转而结束的旧会话数。
