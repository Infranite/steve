- Hub 的数据库查询更快：消息发送队列、统计刷新、MCP 鉴权、会话列表、流程运行、邮件和审计等常用查询有了索引（迁移 035），不再每次扫整张表；连接加大了页缓存，启用 mmap 和内存临时表，并定期运行 `PRAGMA optimize`。写事务改为 `BEGIN IMMEDIATE`，升级切换期间两个进程同时写库时不再直接报 `SQLITE_BUSY`。
- 长时间阻塞不再拖住 Hub：git、git push、gh 和 IMAP 命令都有超时；流程、知识库、邮件同步和保留期清理里的同步数据库操作移出了异步线程；原来轮询等待的地方改为事件通知。
- 修复：飞书长连接收到的消息可能乱序处理，同一会话内现在保持顺序，不同会话之间可以并行处理；邮件保留期清理在有文件删不掉时会一直循环；流程认领到期运行时中途失败，已认领的运行会卡在“运行中”；`/spaces` 和邮件会话列表的 N+1 查询。
- 下载附件和产物时改为流式传输，不再把整个文件读进内存；`/api` 请求体有了默认大小上限，上传接口除外。
