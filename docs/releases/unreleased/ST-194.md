Forward migration/VM progress permits backfills longer than 60 seconds, with a 60-second idle timeout and a 15-minute total limit. Crashes, stalled migrations and unhealthy startup still fail within bounds and restore the pre-upgrade backup before commit. Managed probes also reject unsuccessful HTTP health responses even when their identity metadata matches. Native, managed and compatibility Python probes use the same policy; released migration 076 and the database schema are unchanged.
