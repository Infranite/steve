- With the interface in English, the status line of an item whose work the Hub is judging (collaboration paused, queued, failed, waiting for prerequisites, a Node or the model quota) now reads in English instead of Chinese. Text an agent writes itself is still shown as written.
- The statistics items table no longer shows "<$0.01" for an item whose tokens were mostly on a model with no price. It shows the unpriced tokens next to the estimate, for example "— · 7.4M unpriced", with the priced part as a lower bound. The item drill-down does the same in its cost figure, its turn rows and the usage line on the item page.
- The items board folds a status with no items into a narrow rail and gives the room to the columns with cards, so the board fits the page at common laptop widths instead of scrolling sideways.
- A remote Node that reaches the Hub but cannot link (for example because the Hub could not accept its hello) now tells the Hub why. Devices shows the reason for that Node while it is disconnected, as it already did for the Hub's own Node, and work waiting for the Node says why. A Node that cannot reach the Hub at all still records the reason only in its own log and `link-status.json`.
