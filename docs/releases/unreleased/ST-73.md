Bot 可用 `steve_deliver_file` 将文件或 ZIP HTML 包完整接收到 Hub，获得不可变版本的登录访问地址；`steve_deliver` 的文件产出复用同一链路。源目录清理、执行结束或 Node 离线后，已接收的文件仍保存在 Hub。

新增交付元数据、原文件下载、包内资源和独立分享授权接口。公开分享必须由用户另行授权并指定到期时间，可随时撤销；Bot 会话令牌不能创建分享。HTML 以静态沙箱展示，禁用脚本、表单、框架和外部连接。接收拒绝路径穿越、链接、超限 ZIP 和不完整或变化中的文件；每日备份包含交付对象。

事项产出接口补充经 Hub 登记并校验同事项、同工作区的 `delivery_id`，供事项和聊天交付卡片打开及下载文件，旧路径和外站链接继续兼容。交付页面 URL 绑定所属工作区，避免用户切换工作区后打不开有权访问的文件。Bot 返回的访问提示同时说明本机地址的可达性限制和 HTML 静态预览限制；公开分享仍保持相同的静态行为。
