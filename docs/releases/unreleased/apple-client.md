- 新增 macOS（`SteveMac`）与 iOS（`SteveIOS`）原生客户端（`apple/`）：启动默认自动连接本机 Hub（`127.0.0.1:8440`），支持添加、保存并在多个 Hub 之间随时切换，客户端凭证独立保存在系统钥匙串（Keychain）。
- 新增手机扫码配对：已登录的网页端与 macOS 客户端可在「设置 · 访问与客户端」（或工具栏 / 菜单栏）生成 5 分钟有效的一次性配对二维码（`steve://pair`），手机端扫码即可换取独立客户端凭证并完成接入；Hub 配置了公网地址时默认走公网连接（公网不可达时自动回退局域网），未配置公网地址时自动走局域网连接。
- macOS 客户端新增菜单栏状态图标（`MenuBarExtra`），实时展示当前 Hub 连接状态、连接路径（本机 / 局域网 / 公网）、版本号、工作区、运行中会话数、待处理决策数与在线设备数，支持快速切换 Hub、打开扫码配对与直达主窗口。
- 网页端新增多 Hub 列表管理与切换，支持保存多个 Hub 地址并在「设置 · 访问与客户端」、登录页与命令面板（`⌘K`）中切换或打开手机扫码配对弹窗。
