- 新增 macOS（`SteveMac`）与 iOS（`SteveIOS`）原生客户端（`apple/`）：macOS 启动默认连接本机 Hub（`127.0.0.1:<STEVE_PORT>`，默认 `8440`），界面即网页端本身，客户端凭证独立保存在系统钥匙串（Keychain），不进入页面脚本。
- 客户端的多 Hub 切换、添加 Hub 与设备配对直接复用网页端的同一套界面：粘贴配对链接、从 `steve://pair` 打开或用 iOS 客户端直接扫浏览器同一个配对二维码，都会先弹出系统确认框展示目标 Hub 名称与地址，确认后才换取并保存凭证；不同 Hub 的会话与本地网关严格隔离，文件上传与需认证的附件下载也直接在客户端内完成。
- macOS 客户端新增菜单栏状态图标（`MenuBarExtra`），实时展示当前 Hub 连接状态、连接路径（本机 / 局域网 / 专用组网 / 公网）、版本号、工作区、运行中会话数、待处理决策数与在线设备数，支持快速切换 Hub，并可直达主窗口的「添加 Hub」与「配对新设备」。
