- 修复事项会话一直停在“正在开始”：打开项目页（读合并队列）、在项目目录里执行流程命令或推送之后，这台 Node 上所有会话的事件都不再被 Hub 接收，新事项的工作区准备好了却永远等不到回执，任务说明一直排着队。原因是 Hub 直接发给 Node 的这类命令不在命令账本里，守卫把它们的回执当成“别的 Node 的工作”整批拒收，Node 每 10 秒重发同一批、永远过不去。现在只拒收账本里记在别的 Node 名下的操作；升级后积压的事件会被接收，卡住的事项自己继续，不需要重建。
- Hub 拒收 Node 的事件时在 Hub 日志里记一条警告并写明原因，不再只有 Node 一侧的日志能看到。
