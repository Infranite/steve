- Nodes now default to 32 concurrent session turns, with a saved per-device setting (1–256) in Devices. The Hub and current Nodes use that setting for actual dispatch and execution; idle conversations, model jobs and commands do not consume turn slots.
- Extra turns queue durably and start automatically as room frees. Increasing capacity releases eligible queued work on the next dispatch; decreasing it lets existing turns finish. No restart or additional approval is needed. Devices shows running/queued counts, and conversations distinguish a full device from the Node's actual refusal or retry reason.
- Existing device rows still at the old display-only default of 4 become 32; custom values are retained. Update older Nodes to the same release as the Hub for live executor-limit changes; older peers keep their own limiter until updated.
