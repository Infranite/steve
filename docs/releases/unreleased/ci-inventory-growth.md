CI checks production function structure in a separate macos-15 job required by the CI gate. Pull requests run it when they change hub-rs/**, scripts/structure_guard.py or .github/workflows/ci.yml (or the path query fails); pushes and merge queue runs always run it. It compares guarded inventories over the validated PR target or full fast-forward push range. Normal budget reductions pass without authorization. Reviewed increases require `Inventory-Growth: <path> <key> = <complete head result>: <reason>`; key fields retain their inventory TAB separators, and the same key changing again cannot reuse a different result. First imports use a full Git blob anchor verified in that path's candidate history, so initialization cannot approve later increases. Removed inventories need a named removal reason, and target layering remains subject to normal review.
