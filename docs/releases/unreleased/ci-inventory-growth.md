CI checks production function structure on macOS shard 1 after tests and report upload. It compares guarded inventories over the validated PR target or full fast-forward push range. Normal budget reductions pass without authorization. Reviewed increases require `Inventory-Growth: <path> <key> = <complete head result>: <reason>`; the same key changing again cannot reuse a different result. First imports use a full Git blob anchor verified in that path's candidate history, so initialization cannot approve later increases. Removed inventories need a named removal reason, and target layering remains subject to normal review.
