- 多 Hub 切换与设备配对现在是网页端自己的功能，浏览器与 macOS / iOS 客户端里是同一套界面：侧边栏顶部的 Hub 切换器（手机上在「我的」页），登录页与「无法连接」页的 Hub 列表，「设置 · 访问与客户端」里的完整列表，以及命令面板（`⌘K`）。
- 添加 Hub 时填地址或粘贴配对链接都可以。同一主机不同端口、或 HTTPS 的 Hub 在当前页面内直接切换；其他主机上的 HTTP Hub 会跳转到那个 Hub 自己的页面，已保存的 Hub 列表随地址一起带过去，经你确认后才加入。
- 配对二维码现在是一个任何浏览器都能打开的链接：没装 App 的手机用系统相机扫码即可在浏览器里完成登录，iOS App 扫同一个码也可以，链接还能复制到另一台设备的「添加 Hub」里。二维码 5 分钟内有效、只能用一次；Hub 有多个地址时可以选择设备够得着的那个。
- 同一台主机上的多个 Hub 现在可以同时保持登录：Hub 的 Cookie 名带上了自己的端口。升级后，已登录的浏览器需要重新登录一次。
- 开启了独立网页端口（`STEVE_WEB_PORT`）时，用浏览器打开 Hub 的 API 端口会自动转到网页端口。
- 未设置 `STEVE_PUBLIC_URL` 时，默认地址跟随 `STEVE_PORT`，不再固定为 8440。
- 浏览器重新登录同一个 Hub 时，被替换掉的旧登录会随之失效，不再在客户端列表里越积越多。
