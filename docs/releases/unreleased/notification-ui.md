Settings → Notifications now loads and saves your personal notification policy, with retryable errors and explicit opt-in from the moment you save; older events are not backfilled. Read entries in the separate Feed, with caller-scoped read state. Immediate mode requires explicitly selecting a verified reachable bot DM from the notification-targets API and never silently replaces an unavailable saved conversation. Quiet hours accept cross-midnight local times in an IANA time zone. Only work-item completion (`work.item.done`) is connected; digest/log accumulate entries without generating or scheduling summaries. The old inactive workspace quiet/digest-time preferences are no longer presented as working notification controls, and Feed reads do not dismiss workspace notices or mark external messages read.
