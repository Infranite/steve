每日备份可在设置页开启或关闭，并选择保留天数，默认开启、保留 7 天。关闭后停止生成新日备份，已有日备份仍按所选期限清理，最新一份保留。安装运行配置仍可停用自动备份。升级前、破坏性操作前、手动和诊断备份不受每日开关影响。

网页立即备份和默认管理命令创建的手动备份不会自动删除，也不占用自动备份的容量额度；状态单独报告手动备份用量和最近一轮清理失败数。每日、升级前、破坏性操作前和诊断备份统一由后台按用途清理，内部容量保护会优先删除最旧的可清理副本，各用途最新一份始终保留；受保护副本造成超限时状态可见。诊断备份只复制数据库，其他用途按统一规则附带文件。以 STEVE_NO_RESUME 运行的数据副本不清理备份目录。
