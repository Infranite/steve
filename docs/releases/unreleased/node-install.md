- 可以从 Hub 远程安装 Node：在“设备 · 添加设备”里选“通过 tailcat 远程安装”，在目标机器上运行页面给出的一行 `tailcat serve --ssh-authorized-keys='…' ssh`（只接受这次安装生成的密钥），再把它输出的地址贴回来。Hub 随后自己完成：识别平台，下载与 Hub 同版本的安装包并核对 SHA256，经隧道发过去，安装、配对并启动 Node，页面上逐步显示进度。配对码经标准输入传递，不出现在命令行里。这样装的 Node 配对后直接可用，不需要再手动核对指纹。新 Node 经 tailcat（已开启时）或 Hub 的 HTTPS 地址连回来；访问不了 GitHub 的 Hub 可以用 `STEVE_NODE_INSTALLERS` 指向放有发布文件的本地目录。Hub 所在机器需要 tailcat 和 OpenSSH。
