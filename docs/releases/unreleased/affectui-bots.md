- The Bot list shows each Bot as a card: its avatar, name and role, then the harness, model, running items and memories underneath. Click anywhere on a card to open the Bot. The on/off switch and the ⋯ menu on the card still work on their own and don't open it.
- A Bot's Capabilities tab lists its tools as tiles you can filter by group: Steve's own tools, tools from other connected MCP servers, and the tools built into its harness. Each tile shows how often this Bot called the tool in the last 30 days, and each group lists its most used tools first. A tool from another MCP server shows its own name with the server it comes from. Steve's core tools are always listed, even when unused. Tools built into the harness and tools from other MCP servers show up once the Bot has used them.
- In a Bot's Settings, the permission mode and how its work is accepted each have their own section. Every option is a tile with a short name and a plain-words description. The permission section also notes that, in every mode, anything a Bot sends out through Steve, such as mail or GitHub actions, waits for your approval. The model field looks like the other fields beside it, and the New Bot dialog uses the same tiles to choose how to start. As before, changes apply when you press Save.
- A Bot's Memory tab uses the same memory panel as the Knowledge page. Add a memory with New memory, edit one in place, or forget it with a few seconds to undo. A memory you forget is still deleted if you close or reload the page before the undo runs out.
- The text fields, selects and switches on the Bot pages and in the New Bot and Delete Bot dialogs now match the ones on the settings pages.
