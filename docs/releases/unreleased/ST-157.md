Assistant replies now retain permitted local Markdown images in the Hub's authenticated attachment store, including temporary images from full-access research. Their original alt text and workspace remain in `/api/files/<id>?ws=<workspace>` references, which stay readable after the Node cleans up its source.

Image capture checks execution scope, file integrity, size and decoded raster content. Code examples, sensitive paths and links cannot cause file reads; failures preserve the normal text response. Research tools receive an execution-specific `TMPDIR`; shared temporary paths and historical missing images are not recovered.

Capture now confirms GFM image semantics, so Markdown-looking text inside literal web URLs never reads or uploads local files. Invalid image content releases its upload budget immediately; abandoned, cancelled or timed-out transfers have bounded cleanup, while temporary disconnects and successful retries retain their existing resume and deduplication behavior.
