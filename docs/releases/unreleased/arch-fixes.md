- 多表业务写入（配置变更应用与撤回、事项工具提问/审批/计划更新、失败卡片生成、依赖变更、目标修订等）现通过可重入的 `Store::atomic` 在同一 SQLite 事务中提交或整体回滚；嵌套写作用域通过 `SAVEPOINT` 隔离，变更事件、诊断记录与 outbox 唤醒统一在外层提交后发出。
- 开启 `STEVE_PRINCIPAL_STATE=on` 后，Owner 可通过已认证的 `GET /api/sessions/{id}/principal-state` 直接查询会话的凭据主体状态，无需再使用开发态内部 Header。
- Hub 事件总线的内部监听通道改为有界队列加同键溢出合并，慢消费者不再无限堆积内存；`/api/state` 缓存改为按工作区统计变更代数，不再因其他工作区的写入被连带清空。
- 知识库同步到 OpenViking 时，先读出分块并归还 SQLite 读连接，再发起远端 HTTP 写入，避免慢网络响应占满读连接池拖慢普通请求。
- Hub 的 `wire::node_runtime` 按生命周期、规划、派发、收件、落库与对账拆分为独立子模块，保持原有行为与边界约束不变。
