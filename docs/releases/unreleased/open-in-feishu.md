- A conversation, a chat message and a card about a chat message from Feishu or Lark now have 在飞书中打开 (Open in Feishu). It is in the conversation's header, in the actions under each message of the conversation, on the group's page and on 待处理 cards about a chat message. It opens the chat in the Feishu client on a computer and in the Feishu app on a phone, through Feishu's AppLink (`applink.feishu.cn`, or `applink.larksuite.com` for a Lark connection, by the connection's domain setting). Feishu has no link to a single message, so a message opens its chat.
- It works for chats seen through the Feishu bot, your own Feishu account and a channel service that says it reaches Feishu. A chat whose id is not a Feishu chat id gets no link. The Hub gives the link as `open_url` on spaces, conversations, chat messages and `chan_message` decisions, so other platforms can add their own links later.
