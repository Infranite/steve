- A deploy no longer waits for an agent turn that is only waiting for your permission answer. Such a turn, and any idle session, is paused for the restart and continues on its own afterwards; the same permission request comes back as a fresh card. Turns that are doing work are still waited for. If the deploy is called off instead, the paused turns continue right away. A pause for a deploy doesn't count against the "resumed already within half an hour" limit, and other open cards on the item don't keep it from continuing.
- A lifecycle test no longer reads "closed" before a dropped item's last turn has wound down.
