- 启用本机 Node（`STEVE_NODE=local`）时，Node 会话的运行状态和旧运行器一致：消息发出、回合排上后就显示“运行中”（harness 还没开出自己的会话时显示“启动中”，开始执行后转为“运行中”），回合结束后显示空闲，出错结束时显示出错，不再一直停在“启动中”；已结束的会话保持结束。结果不确定（等待对账）的执行，包括 Hub 或 Node 在 harness 还没开始执行时重启的情况，在点停止放弃前一直显示运行中。会话开始运行时，事项上的“它停下了”卡片同样会自动失效。Node 会话现在也记录 harness 自己的会话 ID，会话里能看到并复制这个 ID 和在 harness 里接着用的恢复命令。
