Device configuration now checks the current owner's permission, configuration revision and write in one transaction, so a request waiting behind a committed revocation is rejected without changing the device. The concurrency editor, API and Store accept integers from 1 through 256 and preserve existing values such as 32 when pausing or resuming. Older clients without a configuration revision receive a 400 response and must refresh or upgrade; stale revisions still return 409. These settings affect new turns only, preserving queues, accepted attempts and retries.
