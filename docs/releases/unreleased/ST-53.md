The Release build no longer fails at random in the thread, merge-lane and Feishu registration tests, and a Release run started again for an older tag no longer fails its migration check. (ST-53)

- A message that waited for Steve's turn now always comes after that turn's last word. When you stopped an answer, the "好，停下了" note and the waiting message could be written in the same millisecond and then show up in either order; the waiting message now moves strictly after the last message of its conversation.
- The migration check compares a version with the release just before it. Re-running the build of an older tag compared it with a newer release, and failed on the migrations that release added.
- Two tests waited for the wrong signal: the merge-lane test checked the lane before the request had left it, and the Feishu registration tests took a saved credential for a finished check before the check had started.
