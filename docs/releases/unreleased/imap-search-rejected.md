IMAP synchronization now reports rejected UID SEARCH commands as errors and keeps the unconfirmed window for retry, instead of treating rejection as an empty mailbox and permanently skipping messages. A server that rejects SEARCH SINCE is reported as an error; Steve does not fall back to scanning the entire mailbox. Message-ID lookups also report search rejection instead of saying the original message is gone. Previously advanced cursors are not reset, and mail skipped by earlier versions is not backfilled.
