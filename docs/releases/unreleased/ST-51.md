- **A reopened item shows it is running once work starts on it.** After a new cycle, a message or a supplement to the item, or the bot reporting progress, moves it from "等你" to "进行中" with a current summary instead of "新周期，等你说要做什么". Only an open card — an approval, a question, an acceptance — keeps it waiting on you. The plan of the cycle before is kept as an earlier round, so the new cycle no longer shows the old 4/4.
- **The items list says what a waiting item needs from you.** A row waiting on a card shows what the card asks ("审批：…", "问题：…", and how many there are) and a button that takes you to it ("去审批", "去回答", "去验收").
