Needs a minor release: backup receipts and restore commands now use restic snapshot IDs. Upgrade through the native installer if an older source updater rejects the new bundle contents.

Steve now uses one encrypted, deduplicated backup repository under `backups/restic` for daily, manual, upgrade, destructive-operation and diagnostic copies. The Data and privacy page shows total repository use, and Health warns when its destination is low on space. Automatic backups retain the latest copy of each purpose and use time and count limits. Manual snapshots stay until you remove them.

Keep the repository password and Vault recovery keys separately from off-machine backups. Existing backup directories stay in place. Restore or retire those copies manually using the earlier format, and use the new snapshot ID for new restores.
