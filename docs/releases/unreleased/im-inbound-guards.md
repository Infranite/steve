- 聊天消息有了“水位线”：接入（或重新接入、恢复、开启新能力）之前写的消息，以及写完超过 30 分钟才送到的消息，现在只存为旧消息并记录下来，不再运行规则、触发词、意图判断、流程，也不起草回复、不建卡片。不管消息是哪个适配器（包括插件）送来的，都由 Hub 统一把关。判断时给双方时钟留了 2 分钟余量；被编辑过的消息从最后一次编辑的时间算起。迟到的时长可以按账号设置（`PATCH /channels/:id` 的 `late_minutes`，1 到 10080 分钟），账号信息里会显示有多少条接入前的旧消息和迟到消息。在会话里，这些消息照常显示，旁边带一个不显眼的“旧消息”标记。只因旧消息出现的新群，会等有人现在说话时再问你要不要设置。
- 你本人发的消息不会再被当成别人的消息来起草回复：在以你本人接入的账号上，发送者是你的“我”、并入了“我”的联系人，或者发送者的句柄是“我”的账号句柄、别名或你的登录邮箱时，这条消息就算你自己的，不起草、不发送、不建确认卡片。（发给机器人的消息照旧由机器人回应。）新出现的联系人如果和“我”同名、邮箱域名也是你在用的，或者邮箱就是“我”的别名，会出现一张“可能是同一人”的合并建议卡片，只是建议，不会自动合并。
- 新增智能体工具 `steve_im_read`：任务需要时读取某个会话在一段时间里的消息（参数 `space`、`from`、`to`、`limit`），只作上下文，不会回复、不会触发规则或流程、也不会存成新消息。它只读你能看到的会话，带上会话的披露级别，屏蔽或不使用的会话不读，输出有长度上限。渠道插件可以提供可选的 `HistoryRead` 能力（Extension API 2 内新增，不破坏现有插件）从平台实时读取；没有提供时读 Steve 已存的消息。内置的“飞书 · 你本人”已支持实时读取。
