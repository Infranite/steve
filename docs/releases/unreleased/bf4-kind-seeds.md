Built-in delivery tags are created only when a workspace is first created, including the initial default workspace. Deleted or renamed delivery tags are not recreated by startup, task creation or later tag changes. An existing workspace without them is left unchanged. New tasks and new outputs can still use delivery tags that remain available; ordinary tags of the same name are left in their chosen category and are never attached automatically as delivery tags.

Initialization no longer moves nonstandard tags from the type category into the topic category or infers delivery tags from historical item titles, goals or artifacts. Existing item tags are left unchanged. The obsolete delivery-backfill checkpoint setting is deleted at startup and is no longer hidden by a special settings filter. No manual upgrade action is needed.
