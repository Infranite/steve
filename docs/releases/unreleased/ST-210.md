Devices now checks CLI and ACP component versions on each selected local or remote Node and offers one-click upgrades for installed components in that Node’s managed prefix. Checks show latest versions, times, failures and unsupported or external installations. Upgrade results come from durable Node receipts and verified installed versions, with progress, failure and unknown outcomes retained across refreshes and reconnects.

This optional capability requires an updated Node; older Nodes keep working and show the upgrade steps. The instance owner’s authorization and the Node’s execution ceiling both apply. Active work and other installers block component changes; package failures require an explicit retry. Provider, model and sign-in configuration stays on the Node and is not changed.
