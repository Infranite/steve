- Settings → Appearance → Font size and Reduce motion now take effect. Large makes all text in the web client about an eighth bigger: the type scale, Markdown, the composer and the controls. Spacing and widths stay the same, so pages keep their layout. Reduce motion stops transitions, animations, page cross-fades and smooth scrolling, just as the system's own reduced-motion setting does. Both settings are stored on the Hub and apply to every browser you sign in from. Each browser remembers the last values it saw, so pages open with them right away.
