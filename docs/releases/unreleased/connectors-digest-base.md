会话梳理增加确定性输入与持久存储底座：先读取 Hub 已存的聊天和邮件，每会话独立画像、设置和游标，默认 50 条窗口，可改为 500 等较大窗口并按预算分块。梳理包保存真实消息、联系人、回复链、引用与候选关联，晚到消息不会因时间游标而漏掉，失败重试保留已完成块。

增加跨会话 matter、个人待办，以及现有记忆的会话／人／事／消息范围索引和 owner API。个人待办不等于交给 Bot 的 item；自动来源的截止时间必须有引用原文。队列可检查和显式重试，来源访问沿用会话可见性，不扫描其他成员私有接入。本阶段不启动摘要 Bot、不调用模型、不抓取连接器历史，也不包含专用 UI 或自动知识／待办判断。
