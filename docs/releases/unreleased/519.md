Needs a minor release: the Node protocol carries file-access observations. Update the Hub and its Nodes to the same release before resuming work.

- On a macOS Node, the first interactive `steve node enable-boot` checks access to configured protected locations. If it finds a denial, it opens Full Disk Access settings with your approval and shows the exact supervisor executable to enable. Run `steve node file-access` on the Node to repeat the check after changing its folders or permissions.
- Devices shows the Node's file-access status and lets you recheck after granting access. The macOS service keeps its signed supervisor in place as you switch release bundles.
