- 运行沙箱分为三级（`STEVE_CONFINE`）：
  - `0`：不隔离。
  - `1`（macOS 默认）：文件系统物理隔离。在工作目录里运行的 agent 和流程命令只能写自己的工作目录（包括 worktree 所属仓库的 `.git`）、harness 与工具链目录、临时目录、常用的工具缓存（npm、cargo、go、pnpm 等）以及 harness 自己的主目录（`~/.claude`、`~/.codex`）。其他位置只读，Steve 自己的密钥和数据照旧不可访问。环境变量保持用户系统原样，不做任何改动。
  - `2`：在 1 的基础上，运行进程从用户全新的登录环境启动（由 `$SHELL -l` 得到），再加上 Steve 为它设置的变量。
  
  某个工具需要写到其他位置时，可以用 `STEVE_CONFINE_WRITABLE` 补充允许写入的目录（多个用 `:` 分隔）。Linux 上的沙箱仍需显式开启（`on`、`1` 或 `2`）。Codex 继续使用它自带的沙箱。
