- The YOLO control ("How much Steve can do while you're away") picks its level on a three-stop dial: Off, YOLO and Full access. Under it, Steve lists what each level hands over, split into "Handled for you" and "Asks you first", and the list moves as you change the level. YOLO handles commands in the workspace, accepting deliveries whose checks pass, letting a stopped agent continue, answering agents' questions when it is confident, starting items whose prerequisites are done, releasing your own Steve, Bot replies inside your organisation and [AI]-marked messages. Full access adds any command and any file change an agent wants. Payments, high-sensitivity vault entries, other messages sent as you and releases of other projects are locked and always ask you. The preview of open cards and the full-access confirmation now sit right under the dial, so you see them before the list. While YOLO is paused or unavailable on this Hub, the dial shows Off and lists nothing as handled for you; the saved mode is named on its own line and can still be changed to Off.
- Each of the Long-term memory and Knowledge entry tabs of Knowledge is now a memory panel. It groups memories by kind, with filter chips; the Knowledge search above still finds memories. Each memory shows its subject, source and the day it was saved. You can reword a memory in place, mark it stale (Steve keeps it but no longer uses it) or use it again, and delete it with a few seconds to undo before the Hub deletes it. Reloading or closing the page during those seconds still deletes it. A new memory picks its kind (rule or preference, fact, event or summary) in the panel. Disclosure level and visibility can still be changed on every memory, and memories still waiting for confirmation are tagged as such.
