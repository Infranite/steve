- A push to `main` now needs three macOS runners instead of five: the web checks run on Linux only, and the macOS release-script checks moved into the first macOS Rust shard.
- When GitHub cannot give a macOS job a runner at all, it cancels the job with no step run ("not acquired by Runner"). The new `CI rerun` workflow reruns the failed jobs of such a run on `main`, at most three times, only when every failure is such a job and no newer push to `main` has a run (a rerun would otherwise cancel that newer run's place in the queue). A job that ran and failed is never rerun.
