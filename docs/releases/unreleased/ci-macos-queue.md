- A push to `main` now needs three macOS runners instead of five: the web checks run on Linux only, and the macOS release-script checks moved into the first macOS Rust shard. macOS jobs limit their heavy steps rather than the whole job.
- When GitHub cannot give a macOS job a runner at all, it cancels the job with no step run ("not acquired by Runner"). The new `CI rerun` workflow reruns the failed jobs of such a run on `main`, at most three times, and only when every failure is such a job. A job that ran and failed is never rerun.
