Steve 工具目录现在按会话身份授权：会话启动、两回合之间或暂时没有 attempt 时，仍可完成 initialize / tools/list；实际工具调用仍必须属于当前有效的运行尝试，没有 attempt 时返回可理解的工具错误，不执行操作，也不会让目录消失。如果 Node 报告缺少 attempt、而 Hub 仍记录执行中，会记录状态不一致并自动重开会话。

首条任务发出 60 秒后仍未确认工具挂载，或 Agent 停下时工具未就绪，也会自动结束旧会话、等待执行器释放，并带着已有进展、待处理消息和附件转到新会话，原因记入时间线。连续自动重开最多两次，成功进入有效尝试的 MCP 调用会重置计数；仍未恢复时保留一张人工重试卡。暂停、手动停止、依赖等待、离线及执行结果未知的会话不会被盲目重开。
