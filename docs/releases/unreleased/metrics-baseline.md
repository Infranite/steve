Optional in-memory Prometheus metrics can be enabled with `STEVE_METRICS=prometheus`; the default remains off. The independent `GET /metrics` listener defaults to `127.0.0.1:9464`; `STEVE_METRICS_LISTEN` accepts loopback IP addresses or an absolute `unix:` socket path with mode 0600. Scrapes require an owner's Bearer client credential, using the existing access-token sign-in flow. Lock timing, transaction counts and process disk-write bytes never enter the database.
