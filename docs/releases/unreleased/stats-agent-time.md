- The daily chart on the stats page has a third line: Agent time, the time agents spent working each day (each hour on Today). A turn counts in full on the day it ended, so the days add up to the Agent time key number. The axis is in hours or minutes, and the tooltip and the table show the exact time.
- `GET /stats/series` has two new metrics. `turn_ms` is agent turn time, and accepts the same groups as `turns`. `wait_ms` is the time a person was waited on: for each item, the time any of its cards for you was open, split at local midnight (or the hour). Cards that YOLO answered don't count. `wait_ms` accepts `none`, `bot` and `project`.
