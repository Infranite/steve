- The Stats page is reorganized around the questions it answers. The key numbers for the chosen range now come first, in one row: items done, estimated cost, agent working time, time waiting on you, first-pass rate and average cost per done item. Each one shows the change from the previous range of the same length, and a number with no data behind it is left out. Above them, one slim line shows what is running, waiting on you or failed right now, along with the YOLO state. Click a count to see the items behind it.
- Daily output shows the items done each day as bars, with the estimated cost (or the number of agent turns) as a line on its own axis. Click a day to see the items done and created that day.
- "Where the money and time went" splits the cost, or the agent time, by item, Bot, model, harness or purpose. Below the split are the most expensive items in the range. Click one to see where its cost went, turn by turn.
- Two new sortable tables compare Bots and harness · model pairs. The Bot table shows items done, first-pass rate, failures and rework (with how many per done item), turn errors, agent time and cost per item, cache hit rate and tokens per item. Click a Bot to see the whole page for that Bot only. The harness · model table covers agent turns: turns, success rate, retries, average turn time, cost per turn, cost, cache hit rate and tokens.
- The event explorer moved to the bottom of the page and starts collapsed. Each event kind's count now appears once, on its filter switch, instead of again in a separate row of numbers. The lead-time trend, the quality and agent panels and the separate usage table were removed. Their key figures are now in the key numbers and the comparison tables.
