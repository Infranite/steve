Digest Bots now start when packet-count or packet-age thresholds are met, and expired packet leases are recovered at their deadline instead of waiting for the next minute. A schedule that cannot start records a failed run and retries after a minute without delaying other workspaces. Consecutive startup failures with the same error share one run record instead of filling the run history. Schedule run responses include the startup failure count, and a changed error starts a separate record.
