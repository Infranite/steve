远程安装配对失败或尚未开始时，现在可以选择“取消此次配对”，再添加下一台设备；下一次配对会使用新的安装命令和临时密钥，不再恢复已取消的失败记录。原机仍可直接重试，关闭弹窗仍会保留进度。取消后请在原目标机器上按 Ctrl-C 关闭 tailcat serve。

取消会清理 Hub 上此次安装的临时 SSH 密钥；安装阶段失败后，尚未使用的自动确认配对码也会失效。正在进行或已经完成的安装不会被取消，也不会卸载目标机器或撤销已经配对的 Node。

手动配对设备时，界面会先显示 Homebrew 安装命令和安装说明，再显示 steve setup node；已安装 Steve 的机器可以跳过安装步骤。直连和经 tailcat 的手动配对均提供此指引。
