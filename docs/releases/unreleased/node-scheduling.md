- 远程 Node 的主人在 `policy.json` 里允许执行命令（`"exec": true`）时，这台 Node 也会运行该机器上项目的流程命令、机密使用和推送；否则仍由 Node 自己拒绝。Steve 自己的思考和调研任务仍在 Hub 上运行。
- 新增 `STEVE_NODE_PLACEMENT=spread`：没有项目的事项开新会话时，会交给负载明显更低（按 CPU 数折算后低 0.25 以上）的已连接远程 Node；默认 `local` 不变。远程 Node 仍只接它主人的工作。
- 设备离线超过 `STEVE_NODE_HANDOFF_MIN` 分钟（默认 30，`0` 表示关闭），又有消息在等它的会话时，Steve 会结束这个会话，在新会话里继续事项。新会话带上之前的对话和等待中的消息，并提醒 agent：那台设备上没有推送出去的改动在这里看不到。同时发出通知。离线时长从连接断开时算起，最长不超过 Hub 这次启动以来的时间。
- 修正：本机 Node 以单独进程运行（`STEVE_NODE_MODE=service`）时，流程命令、机密使用和推送也能在它上面运行。
