- In YOLO mode an item's agent can now push its own branch to `origin`, create, edit or comment on that branch's pull request, and open an issue without stopping on an approval card. The branch is the one Steve recorded for the item, never one taken from the command, and only plain forms count (`git push`, `git push -u origin <branch>`, `git push origin HEAD` while the checkout is on that branch, `gh pr create`/`edit`/`comment` for it, `gh issue create`).
- Force pushes, other branches, refspecs such as `HEAD:main`, tags, deleting, other remotes, `gh pr merge`, repository settings, releases and `gh api` writes still wait for you. When a pull request conflicts or falls behind, the agent is now told to merge the default branch in and push again; a force push after a rebase still asks first.
