- 开启本机 Node（`STEVE_NODE_MODE=local`）时，会话已在 Node 上开工作区的事项，交付时冻结的结果、交付后结果有没有变、有没有需要发布的改动、发布的版本是否包含验收的结果，以及按项目约定核对是否已合并、已推送 tag，都由 Node 的 git 判断；发布前的 rebase 也在 Node 上做。Node 一时连不上时，等待验收的事项保持原样，不会被当成结果变了而作废交付，Node 回来后再核对。
- 批准发布后、rebase 之前分支又有了新提交时，这次不会发布，会把 rebase 失败的原因（核对之后分支又动了）交回给 agent 处理。
- 事项在另一台设备上时，交付结果的核对同样由那台设备的 Node 判断；这类项目不能在 Hub 上发布，发布脚本只在 Hub 所在的设备上运行。
