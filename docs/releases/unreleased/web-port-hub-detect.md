- 新安装默认把网页放在单独端口（如 8441）。以前第一次打开时，网页会把这个端口误当成 Hub，显示"连不上 Steve：响应不完整"。现在网页会自动连到提供它的 Hub（`/hub.json` 给出的地址），直接进入登录页；那个地址连不上时，才请你填写 Hub 地址。
- 外网地址（`STEVE_PUBLIC_URL`）是 https 时，用局域网 IP 的 http 地址打开网页也能登录了。以前登录 cookie 一律带 `Secure`，浏览器在明文 http 下会丢掉它，于是一直停在登录页。现在只有请求确实经由 https（代理传来的 `X-Forwarded-Proto: https`，或访问的正是那个外网主机名）时才加 `Secure`。切换工作空间的 cookie 也一样。
