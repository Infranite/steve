- The composers in the main conversation, on an item's page and in a session have a new look and one set of controls. Files, an item reference (#), handing to a Bot (@) and, in the main conversation, the commands (新事项, 新项目, 汇报, 新 Bot) are in a + menu at the bottom left. Typing #, @ or / still opens the same menus as before. Drafts, attachments, pasting and dropping files work as before.
- While a session's turn runs, its composer shows a Stop button (Esc does the same). Once you type, two buttons appear: 插话 tells the working agent now, and Enter does the same; 排队 sends the message when the turn ends, and Option-Enter (Alt-Enter on Windows and Linux) does the same. This replaces the 插话/排队 toggle and the 中断 button in the bar above the composer. While Steve answers in the main conversation, Stop stays available and what you send queues.
- Messages waiting for a turn now sit inside the composer, above the text field, next one first. Each keeps 编辑, 撤回 and 立即发送. A session's composer also shows its harness and model, and how full its context is as a small ring with the percentage, which turns orange from 80%. These replace the harness, model and context figures in the session header and in the runtime line above the composer; when a harness reports no context use, the runtime line says so.
