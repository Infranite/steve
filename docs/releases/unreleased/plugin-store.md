- 新增插件商店：「插件」页不再是占位。实例管理员在这里添加插件库（GitHub 仓库地址、索引文件的 `https://` 地址，或 Hub 所在机器上的一个目录），Steve 读取库里的 `steve-store.json`，自动列出其中的插件，可安装、升级和卸载。官方插件库 [Infranite/steve-extensions](https://github.com/Infranite/steve-extensions) 在新安装里默认列出，但在管理员点“读取”之前不会联网；`STEVE_PLUGIN_LIBRARY` 可换成别的库，或设为 `off` 不带任何库。
- 插件是预先构建好的压缩包，安装时按库里写的 sha256 校验，作为独立进程在 Hub 旁边运行，不链接进 Hub，也不需要编译器；插件崩溃或被卸载不影响 Hub。安装插件等于以 Hub 的用户身份运行它的程序，所以只有实例管理员能添加库和安装，请只添加你信任的库。
- 第一种插件是“渠道”：把 Steve 没有内置适配器的消息系统以你的身份接进来。任何已登录的成员都可以在已安装的插件上填自己的设置并连接，Steve 为这个人启动一个进程并建立一条外部渠道连接，之后它和其他连接一样出现在「接入」里；在那里断开连接会停掉进程并删除它的设置和数据。连接的 token 存在保险箱里，所以要先启用保险箱。
- 插件库的索引格式、渠道插件要实现的约定（环境变量、`/ws` 地址、如何退出）和磁盘上的位置（`<目录>/plugins`，日志在 `instances/<id>/plugin.log`）见 `docs/deployment.md` 的 Plugins 一节。
