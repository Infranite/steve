# Steve v0.2.21

You can now change Steve's own settings by saying so in the main conversation. Steve drafts the change as a card, you press "应用", and you can undo it.

- **One message can change up to three things.** For example, "免打扰改成 22 点到 9 点，开发 Bot 思考强度调到 high" gives two cards, one per setting, each applied on its own.
- **Asking how something is set shows it.** "现在免打扰是几点？" lists the current values without drafting anything. When Steve can't tell what to change, it says so and lists the current values too.
- **More of Steve can be changed from the conversation:** Steve's settings, Bots, projects, tags and models, plus YOLO mode, schedules, flows, event sources, knowledge sources, mailboxes, GitHub repositories, channels and outward identities. Contacts and teams can be changed when the message names them. Changes to these modules are stored and can be undone for 24 hours.
- **New things to change:** a Bot can be turned off and on again (not the main Bot), a project can be archived, and tags can be renamed, moved to another category or deleted. Only tags that nothing uses are deleted. A tag still in use stays, and the card says why. Undo brings a deleted tag back with its name and category.
- **Cards remember what happened.** Applied and dropped cards stay that way after a reload, and an applied card has its own "撤销" button. "放弃" now tells the Hub, through the new `POST /api/config/:id/drop`.
- Asked whether it can change its settings, Steve now says yes and gives an example, instead of saying it can't. Changing Steve's code or pages is still work for an item, and chats in IM groups still can't change settings.

No database migration (schema 30). Hub and Web must come from the same release.
