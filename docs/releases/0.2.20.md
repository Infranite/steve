# Steve v0.2.20

Settings · Models is shorter: one default and the few purposes set apart, instead of a long list of every purpose.

- At the top is the default: Steve's harness, model and thinking effort, with a button to change it on Steve's Bot page.
- Purposes with their own setting each get one row: the purpose and a summary of its model. Purposes that follow the default are folded into "其余 N 项跟随默认"; open it, or use "添加单独配置", to give one its own setting.
- Editing happens in a side panel: follow the default, or pick a harness, model and thinking effort. Without a model chosen, a purpose on Steve's harness keeps following Steve's model, so changing the default still moves it. Fallback models and the recommended choice are under "高级选项".
- What each purpose actually ran on in the past 7 days is in "运行记录" at the bottom of the page, apart from the settings. Calls that ran on something the purpose no longer uses are marked "非当前配置". Failures are summed up in one notice that opens the record.

No database migration (schema 30). Hub and Web must come from the same release.
