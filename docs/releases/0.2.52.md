# Steve v0.2.52

- 界面选了英文时，Hub 返回的文案也改为英文：错误提示和 404、设置项、事项类型、决定与卡片、流程、渠道、邮件、GitHub、知识库、统计和升级状态等界面上显示的文字。网页在每个请求上带上当前语言（`Accept-Language`，事件流用 `?lang=`）；没带语言的客户端（CLI、MCP、旧网页）看到的中文和以前完全一样。发给模型、IM 和邮件的内容、写进时间线的记录和 YOLO 的执行记录、事项开不了会话时的卡住卡片，以及对话里改配置生成的草稿（标题和改动预览，其他成员在改动记录和决定卡片里也会看到）仍是中文。统计页的缓存按语言分开，中英文用户同时查看同一空间不会串语言。
