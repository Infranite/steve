# Steve v0.2.78

Homebrew installation and tap synchronization download installer assets through GitHub's official asset API, using fixed asset IDs from the published release. Installation requires no GitHub token. Synchronization retains the pinned release identity and size/SHA256 checks, binds the Formula URLs to its release lock, and removes API credentials before following redirects to release storage.

Install and maintain Steve through a native CLI, without a Python runtime dependency. Homebrew installs the precompiled executable directly; the new installer omits obsolete Python launchers. Setup defaults to listening on `0.0.0.0:8440` and configures the browser/OIDC callback URL separately. Interrupted unsigned setup can resume after a package update without deleting its home.

Hub and Node service management, signed Hub release preparation and deployment, offline upgrade journals, backups and recovery now share native installation code. Existing identity, pairing and database safeguards remain. Old runtime archives retain the compatibility scripts required by already-installed upgrade clients; those clients use their existing interpreter for the first transition, while new installations and subsequent native upgrades do not require it.

Make the Node tool timeout/cancellation replay check deterministic under scheduler load. It now proves the service has started before advancing test time, while preserving the uncertain-result and exactly-once execution assertions. Application behavior is unchanged.
