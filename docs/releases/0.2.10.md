# Steve v0.2.10

This release makes your private chat with Steve behave like a private chat: answers arrive sooner, unchanged, and with Steve's tools behind them.

- In a chat only you can read (the bot's private chat with you, nobody else in it), replies are no longer run through the disclosure model or rewritten before they go out. Secrets are still blocked and knowledge marked never-to-use is still withheld. Group chats, chats with colleagues and outside people are checked as before.
- Steve answers there with its read-only tools instead of a tool-less reply, and is told it may answer you plainly instead of keeping internal details from you.
- Research reads the items you mention (also from the last few turns, so "是的" after "查一下 ST-23" works) and can list your agent sessions, how many are running and what they are on. Both only in your own conversations; shared chats still ask the item tool and get no session list.
- A finished item that came from your private chat is reported there at once instead of waiting as a draft.
- When the disclosure check itself fails, a reply is no longer "rewritten" without a reason; it waits for you unchanged.

No database migration (schema 26). Hub and Web must come from the same release. No new provider permissions are requested.
