# Steve v0.2.25

An item's card in the conversation no longer breaks when its Release build fails.

- A Release build that fails after an item is done now shows as its own line on the item's card: a warning icon, the sentence, and a link to the run. Before this, the Hub filed the whole sentence as the released version, so the card read "已发布" followed by a long line that squeezed out the title and ran past the card's edge. Cards written that way earlier show the new way without a migration, and a long version on the card is cut off instead of widening it. (ST-37)

No database migration (schema 30). Hub and Web must come from the same release.
