# Steve v0.2.13

Small fixes that make Steve safer to use from several tabs and less likely to stall or redo work.

- Every request says which workspace it is for. A page whose workspace is no longer yours is refused instead of quietly working in another one, and a page opened before this release asks you to refresh before it can change anything. Switching workspace in one tab no longer redirects another tab's actions.
- "收到" goes on a Feishu message in the background: a slow reaction API no longer delays the answer.
- A tool permission card lives only as long as its turn. Interrupting a turn while it waits for your permission now really ends it (the pending request is answered "cancelled"), and the card closes. A card from an earlier turn or an earlier run of the agent can never be answered into a newer one, and interrupting one turn no longer affects the next.
- When Steve answers in the main conversation with attachments, Read is the only tool it has; your own allow rules can't widen that.
- When the model gateway fails after the agent has already used tools in a turn, the automatic retry asks it to check what is done and continue, instead of sending your message again and repeating the work.

No database migration (schema 26). Hub and Web must come from the same release. No new provider permissions are requested.
