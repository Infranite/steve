# Steve v0.2.32

On an item page, one run now shows its progress once, with one clock and one way of counting.

- When a comment (an approval, a 补充) starts a new turn in a running session, that turn shows only under the comment. The expanded session block no longer repeats it; a line there points to the comment instead. (ST-48)
- The comment's reply and the session time a turn from the prompt that started it, so the two clocks no longer drift apart, and a reload shows the same time. When a turn stops midway for a tool permission, the work after it is timed from its own first step rather than from the prompt again.
- A folded reply sums up its work the way the work block does ("运行 4 条命令 · 改动 1 个文件") instead of "调用工具 N 次". Opened, the work block carries that summary and the clock, and the header names only the Bot and session. A reply stays open or folded when new lines arrive above it.
