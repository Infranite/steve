## Features

- **items:** close owner-finished cycles with one typed item lifecycle (#443) ([#533](https://github.com/Infranite/steve/pull/533))

  Marking an item finished closes its current cycle immediately, even when the item is paused, waiting on a prerequisite, or still running. Session stop and workspace cleanup follow after the completion is recorded.

  The item view carries its lifecycle state, cycle, CAS revision, delivery revision, and delivery references. A GitHub-connected owner can declare a set of required pull requests with `PUT /api/github/items/{id}/delivery`, supplying `cycle`, `revision`, and the `pulls` array of linked GitHub pull-request IDs. Automatic completion with declared pull requests waits for every accepted range to be present on its repository's current default branch. A change that was reverted or cannot be verified leaves the item open.

  GitHub no longer opens or merges pull requests as an item completion step. Agents can request approval to open a pull request. Owners can request a merge approval for the current head from the repository's PR list.

  Project completion uses the item’s declared delivery. Executable release scripts remain available through a dedicated release approval.

  A custom project release script that reports to the Hub must copy `STEVE_RELEASE_OPERATION` into the `operation` field of `releases/last.json`. This ties the report to the approval that started the script.
- **decisions:** settle every decision through one entry with natural keys and typed status ([#538](https://github.com/Infranite/steve/pull/538))

  A repeated answer to the same decision version cannot apply its effect again. Steve keeps the answer separate from the result of any external operation.

  The inbox translates structured prompts in the language selected by the reader. Permission requests, channel drafts, knowledge confirmations and secret-use approvals are expired by the same Hub job.
- **harness:** add Antigravity CLI (agy) as a built-in ACP harness ([#539](https://github.com/Infranite/steve/pull/539))

  Antigravity CLI (`antigravity`, binary `agy` on `PATH`) is now a built-in ACP harness. Steve launches it via `agy acp`, discovers its models, thinking levels and permission modes (`plan`, `default`, `accept-edits`, `auto`), maps native YOLO auto-approval to `auto`, reserves `--dangerously-skip-permissions` exclusively for `full_access`, isolates per-principal state via `--gemini-dir`, and supports resuming sessions with `agy --resume <id>`.
- **web:** split the Node page into six task tabs ([#541](https://github.com/Infranite/steve/pull/541))

  Reorganized the Node detail page into six URL-backed tabs (**Overview**, **Harnesses**, **Work & Resources**, **Access**, **Version**, and **Diagnostics**) so the default view immediately answers whether a Node can take work, pins blocking actions at the top with shared action controls, and tucks identity fingerprints, logs, and raw state JSON into **Diagnostics**.

  Not covered: the Hub keeps only the latest upgrade record and has no live log stream, so Version shows the latest upgrade/rollback and Diagnostics points to `steve node status` / `steve node doctor`.
