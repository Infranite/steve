# Steve v0.2.85

外部线程里的后续消息直接送到对应事项，不再每条都重新路由：

- **飞书**：一条消息做成事项后，同一话题里发起人和你的回复会直接送进这个事项会话，不需要再 @ 机器人。其他人的回复照常处理；事项关闭后的回复也照常处理。别人的话会作为引用的数据交给 Agent。
- **GitHub**：关联到事项的 PR 下，仓库 owner、成员和协作者的评论、review 和行内评论会作为补充送进事项，同一条评论只送一次；其他人的评论仍然只记成信号。事项已经关闭时，会在对话里告诉你。
- 新建的 GitHub App 和仓库 webhook 会订阅行内评论事件（`pull_request_review_comment`）。已有的 GitHub App 需要在 App 设置的事件订阅里勾选 “Pull request review comment” 才能收到行内评论。
