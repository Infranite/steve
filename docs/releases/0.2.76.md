# Steve v0.2.76

主体独立运行目录、工具链输出与缓存归位、远端 Node 配对入口和有界磁盘采样现已默认开启，仍可分别显式关闭。远端设备仍需一次性配对与指纹确认，不会自动取得工作目录、凭据或任务；诊断数据库副本不会启动本地 Node 或接入远端 Node。

预检和启动日志会明确提示本地 adapter 缺失及独立目录的登录准备。已有会话保留原目录，新会话的 Codex 登录不会自动复制。目前尚无独立目录登录的正式 UI/API，部署指南明确此配置缺口，并提供授权操作者的只读定位与本人登录步骤、关闭开关说明。未完成的多 Bot 执行、主体隔离与审批边界没有放宽。

新事项和新会话项默认开启一次 30 分钟的详细调试采集，包含协作生成的子事项。截止时间从创建时起持久保存，刷新、重启或恢复事项不会延长；到期或手动停止后保持停止。实例所有者可以在调试面板停止采集，或重新开启 1–60 分钟的窗口。已有事项不会被追溯开启。

沿用 7 天保留、每事项 10 MiB 和实例 100 MiB 的上限，只记录白名单元数据，不采集提示词、工具参数或结果原文；Agent 仍只能读取有权访问的诊断信息。

修正工作区回收互斥检查的偶发误报。检查现在以真实回收站目录验证重复调用不操作文件、不释放当前执行者的锁，释放后下一轮完成清理；运行时的安全保留与删除条件保持不变。
