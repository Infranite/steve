# Steve v0.2.83

Steve 更少替 Agent 做判断：

- 交付不再因为计划步骤没勾完、前置事项没完成或缺少目标要求的证据（实际操作、构建）而被拒绝。这些情况会写在交付卡上，由你决定要不要打回。
- 事项会话不再在上下文用到 80% 时被换成新会话，默认交给 Agent 自己压缩上下文。设置里的“交接阈值”新增“不换会话”并设为默认；之前明确选过阈值的工作区不受影响。目标改动再大也发给当前会话，不再另开新会话。
- Harness 出错中断的回合会先自动续一次：Steve 告诉 Agent 出了什么错，并提醒它先核对现状、不要重做已经完成的推送和发布。结果不确定的回合仍然交给你。
- 单个回合的累计输出不再有上限（之前实际是 64 MiB），长时间运行的回合不会因为输出多而被取消。磁盘仍由 Node 的日志额度保护。
- Agent 调用 Steve 自己的工具（`steve_update`、`steve_deliver` 等）时，即使 harness 的询问里没有带工具名（例如 Codex 的 MCP 调用审批），也不再弹审批卡。这些调用由 Hub 逐次授权和记录。
