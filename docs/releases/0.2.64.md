# Steve v0.2.64

- 远程 Node 在支持沙箱之前，只运行它的所有者本人的工作：远程 Node 上的会话直接用那台机器主人的主目录和已有登录运行，所以现在只有当工作区属于 Node 的所有者、并且没有其他成员时，会话、任务和命令才会交给这台 Node。共享工作区（还有其他成员）或别人的工作区里的工作不会再绑到这台 Node 上；已经绑在上面的会话，在工作区有了其他成员后发消息会被拒绝，并说明原因（中英文都有），工作区重新只剩所有者后恢复。
- 远程 Node 有了所有者自己设定的权限上限（Node 主目录下的 `policy.json`）：最高权限模式、是否允许不受限的网络、是否允许运行命令和任务。默认不允许“完全访问”（`bypassPermissions`），也不运行命令和任务，网络和以前一样；Hub 要求的权限超过上限时，Node 直接拒绝并说明原因。要放开，由 Node 所有者在 `policy.json` 里写明，例如 `{"max_permissions": "full_access"}`；写错的配置会让 Node 拒绝启动，不会悄悄退回默认值。Hub 本机的 Node 不受影响。
- 连接 Hub 的地址里带有 `@`（用户信息）、`#`（片段）、`%`、反斜杠或空白时，Node 会直接拒绝：以前像 `ws://evil.example#@127.0.0.1/` 这样的地址会被当成本机地址放行明文连接，实际却连到别的主机。配对请求和之后的连接现在用同一套规则确认是同一台主机。
- Node 上报的费用现在会先检查再计入会话：不是普通非负小数的值（`NaN`、`inf`、负数、科学计数法等）、比之前更低的累计值、单次或单轮超过上限的增量都不计入，并记到日志里，所以会话费用只会增加，不会被清空或压低。上限默认每次上报 100、每轮 1000，可以用 `STEVE_NODE_COST_REPORT_MAX` 和 `STEVE_NODE_COST_ATTEMPT_MAX` 调整。不合理的上下文长度和 token 数也会被忽略。
