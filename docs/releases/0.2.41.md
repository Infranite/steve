# Steve v0.2.41

The Release build no longer fails at random in the Feishu long-connection tests (`media`, `feishu_f34`, `c1_feishu_ws`). (ST-49)

- The test double of Feishu answered the WebSocket upgrade before it registered the connection, so a test that pushed an event right after the client reported "connected" could find no connection. The event was then only redelivered after 15 seconds, while the tests wait 10. The double now registers the connection before such a push goes out, as Feishu does: a push waits up to 2 seconds for an upgrade it has already answered.
