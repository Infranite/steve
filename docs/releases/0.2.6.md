# Steve v0.2.6

This release makes conversations and contacts easier to manage and fixes channel cleanup blocked by historical decisions.

- Conversations use a searchable, paginated list instead of an ever-growing strip. Close and restore are saved per user and workspace; messages and channel processing remain intact. Older conversations beyond the former 200-row cutoff are reachable.
- Pending contacts support filtering, selecting all matching people, bulk ignore, and retrying failed operations without repeating successful ones. Ignored contacts can be restored.
- Organization names and details, contact employment, and email addresses can be edited directly. Profile lookup reports missing information honestly, retries gaps, and preserves manually edited names and employment details. External organization names can be supplied manually when the provider does not expose them.
- Confirmed channel cleanup can delete standalone associated decisions. The preview includes the decision count and execution rejects a changed preview. Completed automatic-action history is retained without dangling decision references; deleting its decision ends its undo capability. Active work and unrelated shared references remain protected.
- Navigation clears workspace-specific views on workspace changes and ignores stale conversation requests.

The database migrates to schema 26. Back up before upgrading; do not point an older Hub at the migrated database. Hub and Web must come from the same release. Provider access still follows the permissions and directory visibility already granted; this release does not request additional scopes.
