# Steve v0.10.1

- macOS Nodes now sign `steve`, `steve-node`, and the boot supervisor (`services/node-boot-runner`) locally on the target machine using a stable self-signed code-signing identity created once inside the Node home (`signing/steve-signing.keychain-db`, with its password stored in the installation key store). Release builds no longer require Apple Developer ID signing certificates.
- On macOS, the first upgrade to this version requires re-authorizing file access once in **System Settings → Privacy & Security → Full Disk Access** (because the signing identity changes from an ad-hoc signature to this machine's fixed self-signed identity). Subsequent upgrades on the same machine reuse the same certificate and designated requirement so file-access grants are preserved automatically; setting up a Node on another Mac requires authorizing once on that machine.
