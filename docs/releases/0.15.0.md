# Steve v0.15.0

## Features

- **web:** give Steve and every Bot the charcoal mascot family ([#646](https://github.com/Infranite/steve/pull/646))

  Steve and every Bot now share one hand-drawn charcoal mascot family. It replaces the generic robot avatars everywhere they appear:

  - the sign-in page and the conversation hero;
  - the empty conversation, the message timeline and the sidebar;
  - Bot lists and Bot settings;
  - the browser tab icon and the app icon.

  **Steve** is the plain classic circle: monochrome, oversized eyes, no accessories.

  **Ordinary Bots** are told apart by three things:
  - their colour;
  - their head roundness. When a Bot has never set its look, both come from a stable hash of its id.
  - an optional role accessory: headphones, glasses, loupe, book, pencil, beret, hard hat, wrench, net or chart. Accessories are drawn at 27 px and larger, and left out of smaller avatars.

  The accessory is an explicit field:
  - Pick it in Bot settings, with a live preview.
  - When Steve drafts a Bot from a description, it chooses one from the same closed list.
  - Existing Bots start without one; nothing is guessed from role names.

  How the faces behave:
  - Light and dark themes only change the colours. The faces stay legible from 16 px to 240 px.
  - Large live faces follow the pointer and react to every conversation cue: input, thinking, replying, inspecting, wary, success, affirm, failure, love, idle. They also have idle gestures, doze after 90 s and wake on activity. With reduced motion they hold clear state poses without continuous animation.
  - Small faces are synchronous, cached SVG. All live faces share one animation clock, which stops when they are idle or scrolled out of view.

  Removed:
  - The `agent-robot-avatar` dependency and its hidden snapshot DOM.
  - The Bot `avatar.skin` field. Migration 149 strips it from stored Bots.
- **brand:** add Steve charcoal-enso logo and wire into README, docs, sign-in, and About ([#655](https://github.com/Infranite/steve/pull/655))

  Add the **Charcoal Enso & Gaze** logo system across documentation headers, GitHub social previews, the sign-in screen, and Settings · About:

  - Added canonical pure-path SVGs under `docs/assets/brand/` (`mark`, `horizontal`, and `stacked` lockups in `light`, `dark`, and transparent `currentColor` `mono` colorways) plus `1280×640` GitHub social previews (`social-preview-light.png` and `social-preview-dark.png`).
  - Updated `README.md`, `README.zh-CN.md`, `docs/architecture.md`, `docs/concepts.md`, and `docs/deployment.md` with adaptive light/dark `<picture>` headers, and removed the retired `docs/assets/art/banner-*.svg` files.
  - Added adaptive `--steve-*` brand tokens, the `<SteveLogo>` React component (with `brand`, `mono`, and `micro` modes), the outlined `Steve` wordmark on the sign-in splash screen, and a brand header banner on Settings · About.
  - Kept application and browser favicons aligned with the charcoal mascot (`PR #646`) while using the Charcoal Enso logo across documentation, social previews, sign-in wordmark, and About surfaces (with `steve-mark-mono.svg` available for 18pt monochrome menu-bar icons).

## Fixes

- **web:** replace misleading item state card sublabels ([#654](https://github.com/Infranite/steve/pull/654))

  Item detail state cards now show sublabels only when they add accurate, non-redundant guidance: running (`working`), `blocked`, `idle`, `asking`, `proposed`, `dispatching`, and `closing` items no longer show misleading or duplicate sublabels, `queued` shows "等 Agent 接手" / "Waiting for an agent", and `paused` keeps "该你了" / "Your move".
- **node:** stop probes recreating retired home and wait for hub device registration ([#660](https://github.com/Infranite/steve/pull/660))

## Other changes

- **ci(release):** run release packaging and identity checks in PR CI ([#650](https://github.com/Infranite/steve/pull/650))

  Pull request CI now builds the Steve binaries with a release identity, packages the release and installer bundles, checks the manifests and Homebrew tap layout, and boots the unpacked Hub with `ops/test-release-identity.py`.
