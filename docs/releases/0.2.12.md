# Steve v0.2.12

Conversations with Steve are no longer cut off after four minutes.

- A research answer used to be stopped after 240 seconds, 24 model turns or 40 tool calls, whatever it was doing. There is no such limit any more: a run goes on as long as it keeps working, until it answers or you stop it.
- A run whose agent says nothing at all for 10 minutes is taken as stuck and ended; what it wrote so far is kept. This is not a time limit on work in progress.
- Limits can still be set on purpose in the `thread.research` setting (`seconds`, `turns`, `tools`, `idle_seconds`); there is no ceiling above them.

No database migration (schema 26). Hub and Web must come from the same release. No new provider permissions are requested.
