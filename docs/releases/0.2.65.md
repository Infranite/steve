# Steve v0.2.65

- README 去掉了"防循环守卫会把失控的空间静音"：这个自动静音目前没有实现，空间只能手动静音。

- 很长的回复和长思考不再拖慢 Hub：以前一条消息越长，Hub 每收一段文字就越慢（第 6000 段时每段约 2–3 ms，所有会话又共用这一个写入线程），几个会话同时输出长消息时界面会明显卡顿；现在每段的开销与消息长短无关，约 40–55 µs，Hub 每秒能记下的文字段数提高到约 7–30 倍。本机 Node 和远程 Node 都受益。升级后第一次启动会为已有消息建一个索引，消息很多时要多花几秒。
- Node 把模型连续吐出的小段文字先合并再记录和发送（最多等 50 ms 或攒到 4 KiB，遇到工具调用等别的事件先发出），最后的文字逐字节不变：按每秒约 85 段的速度，记录、发送和 Hub 存下的文字事件减少到约 1/5，界面最多晚 50 ms 看到文字。
- 传文件时权限提示依然很快：Node 拉附件、Hub 读产物文件时，权限请求和答复不再排在文件数据后面。在 10 Mbps、往返 40 ms 的链路上同时下载 4 个附件时，答复权限的往返从约 800 ms 降到约 110 ms；Hub 同时读 4 个文件时，权限卡片以前要等满 30 秒超时才失败，现在约 110 ms 就到。附件改为同时拉 4 块，在 100 Mbps、往返 20 ms 时从约 2.8 MB/s 提高到约 3.5 MB/s。
- 一个特别大的事件（例如参数很长的工具调用）不会再卡住整个 Node 的事件流：过长的文字拆成几段，其他过长的内容截短并注明。Hub 重启后各 Node 的重连时间随机错开，不再同时涌入。
