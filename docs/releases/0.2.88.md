# Steve v0.2.88

没有设置 `STEVE_REPO` 时，Steve 不再假定自己的源码仓库在 `~/Agents/steve`：源码安装从运行中的程序所在的仓库推断，发行包安装则视为没有。识别“Steve 自己的项目”时，除了配置的路径，也认任何一个 Steve 源码仓库的检出，已经登记的 Steve 项目在新安装里照常被认出。

网页可以和 Hub 分开部署：在没有 Hub 应答的地址打开时，网页会先请你输入 Hub 地址，确认对方是 Steve Hub 后保存在浏览器里，再显示登录。Hub 只对在那里登录过的网页来源（以及 `STEVE_CLIENT_ORIGINS` 列出的来源）开放跨域访问；登录接口和“需要登录”的应答对任何来源可读。Hub 和网页在同一台机器的不同端口时用 HTTP 即可，在不同机器上时 Hub 需要 HTTPS。连不上已保存的 Hub 时，可以在页面上换一个。
