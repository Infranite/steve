# Steve v0.14.1

> Version set manually (`--version 0.14.1`): v0.14.0 was tagged but its release build failed before anything was published (#639), so 0.14.1 is the first release with those changes. Read docs/releases/0.14.0.md for everything since 0.13.0, including Before upgrading: on macOS, owners on 0.13.0 or earlier upgrade once from Terminal with steve-hub --local-release upgrade-macos, not from Settings → About.

## Fixes

- **release:** give the identity test's candidate bundle its Hub and Node binaries ([#640](https://github.com/Infranite/steve/pull/640))

  Fixes the release build. The release identity test built its candidate bundle without `bin/steve-node`, and since #606 the Hub refuses such a bundle. The fixture now holds the Hub and Node binaries, as a real release does. The test also accepts that a forged bundle is refused on the bundled Node's identity.

  Closes #639.
- **node:** reconcile on link attach, cache Node probes, and make timing tests event-driven ([#641](https://github.com/Infranite/steve/pull/641))

  Nodes reconcile with the Hub as soon as they link, and Node discovery no longer spawns the same subprocesses over and over.

  - **Immediate first reconcile.** When a local or remote Node's normal link attaches, initial reconciliation starts at once. Before, it waited for the next 5-second retry tick. Slow machines could therefore take tens of seconds before the first turn ran.
  - **Cached Node probes.** `probe(false)` ran the login-shell probe and 13 serial `node --version` checks on every call. These results now live in the existing 30-minute discovery cache, concurrent callers share a single `node --version` run, and installing or upgrading a harness still invalidates the cache at once.
  - Tests that waited on wall-clock deadlines or polled for state now wait on the event they need. This covers the detached-session exit, a turn's text, the active attempt and the first turn. The test FakeNode delivers events in the order it recorded them.

  Closes #637.

## Other changes

- **ci:** give test runs their own disk floor ([#643](https://github.com/Infranite/steve/pull/643))

  CI test runs set their own disk floor (`STEVE_DISK_FLOOR_GB=1`). Hosted macOS runners can have less than the default 10 GiB free once the build is done. There the Nodes refused to prepare workspaces, and every session-opening test waited out its deadline. The product default is unchanged.

  Closes #642.
