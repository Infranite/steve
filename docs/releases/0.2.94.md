# Steve v0.2.94

- 默认不再指定任何模型：Steve Bot、各用途、新会话都跟随 harness 自己的默认模型。新安装不再预设 sonnet → opus，也不再给分流、起标题、披露检查、流程 Bot 节点预写 haiku 的单独配置。需要时仍可在设置 · 模型里指定，或用 `STEVE_MODELS_SMART`、`STEVE_MODELS_FAST`、`STEVE_DEFAULT_MODEL_CLAUDE` 设置。
- 设备页 Hub 那一行显示 Hub 的版本。
- Hub 刚启动、本机 Node 还没连上时，"运行环境"不再把已安装的适配器误报为"缺少 ACP 适配器"：这时按适配器文件是否存在显示，并在 Node 连上后重新探测。
- macOS 上 `steve hub restart` 不再偶尔把服务留在停止状态：等 launchd 真正卸载旧进程后再重新加载。
