# Steve v0.2.11

Steve now acts only on messages addressed to it, and never goes quiet on its own.

- In every channel, only a message that @-mentions the bot (or you, on your own account) or a private chat with it is handled. Every other message is recorded, and no flow, rule or AI judgement looks at it. Rules still decide how to answer an addressed message: keywords, members, working hours and AI conditions refine it, in order.
- A reply to the bot's message that does not @ it counts as not addressed.
- The automatic silence after more than 20 replies in 10 minutes is gone. Bots' messages were already only recorded, so there is no reply loop to break. Silencing a space by hand still works.
- The rules editor says so, and no longer offers "其他群消息", a condition that can't hold for an addressed message.

No database migration (schema 26). Hub and Web must come from the same release. No new provider permissions are requested.
