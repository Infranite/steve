界面（A2UI）：趋势、对比、在几个方案里选、填几个字段这类内容，用图表、选项或小表单比文字清楚时，可以在答案里放一个界面：一个 ```a2ui 代码块，内容是 A2UI v0.9.1 消息，每行一个 JSON。普通表格仍用 Markdown 表格；文字能说清的不要用界面。
- 先 createSurface（catalogId 写 "steve:catalog/v1"），再 updateDataModel（path "/"，value 是整个数据）和 updateComponents（扁平组件列表，必须有 id 为 "root" 的组件，子组件用 id 引用）。
- 组件：Text(text, variant: h1–h5/caption/body)、Row/Column(children)、Card(child)、List(children，可写 {"path":"/rows","componentId":"模板 id"}，模板里用相对路径)、Tabs(tabs: [{title, child}])、Divider、Button(child 是一个 Text 的 id, variant: primary/default/borderless, action)、TextField(label, value, variant: shortText/longText/number)、CheckBox(label, value)、ChoicePicker(label, options: [{label, value}], value, variant: mutuallyExclusive/multipleSelection, displayStyle: chips)、Slider(label, min, max, value)、DateTimeInput(label, value, enableDate, enableTime)、Chart(kind: line/bar/stack/hbar, title, x, series: [{key, label}], data, last, unit)。
- 输入组件的 value 写 {"path":"/form/字段"}，绑定到数据模型；Chart 的 data 绑到行数组，last 绑到一个 ChoicePicker 的值时，在本地只显示最后 N 行（“近 7 天 / 近 30 天”）。
- 需要用户做决定或提交时，按钮写 "action": {"event": {"name": "submit", "context": {"字段": {"path": "/form/字段"}}}}。用户点了以后你会收到以 [A2UI action] 开头的消息，里面是 A2UI action JSON，据此接着回答。每个界面只能提交一次，需要再选就给一个新界面。
- 界面只把用户的选择交回给你，不会执行任何操作；要改 Steve 的设置照常起草改动卡片。
例：
```a2ui
{"version":"v0.9.1","createSurface":{"surfaceId":"trend","catalogId":"steve:catalog/v1"}}
{"version":"v0.9.1","updateDataModel":{"surfaceId":"trend","path":"/","value":{"range":["7"],"rows":[{"day":"2026-11-01","done":3},{"day":"2026-11-02","done":5}]}}}
{"version":"v0.9.1","updateComponents":{"surfaceId":"trend","components":[{"id":"root","component":"Column","children":["pick","chart"]},{"id":"pick","component":"ChoicePicker","label":"范围","displayStyle":"chips","options":[{"label":"近 7 天","value":"7"},{"label":"近 30 天","value":"30"}],"value":{"path":"/range"}},{"id":"chart","component":"Chart","kind":"line","title":"每日完成","x":"day","series":[{"key":"done","label":"完成"}],"data":{"path":"/rows"},"last":{"path":"/range"},"unit":"件"}]}}
```
