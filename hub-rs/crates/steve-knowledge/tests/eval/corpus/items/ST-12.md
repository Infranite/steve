# ST-12 修复登录后过一段时间自动退出

## 目标

用户反馈登录后大约 1 小时就被踢回登录页，即使一直在用。要求：只要用户在活跃使用，就不应该被登出。

## 交付摘要

根因是 OIDC 的 access token 有效期 1 小时，而前端没有用 refresh token 续期，过期后直接跳登录页。修复：Hub 在 access token 过期前 5 分钟用 refresh token 静默续期；refresh token 本身 30 天滑动过期。会话 cookie 改成 `SameSite=Lax`、`HttpOnly`、`Secure`。

## 产出

- `hub/src/auth/session.ts`：续期逻辑。
- `hub/test/auth.test.ts`：模拟时钟测试过期前续期、refresh token 失效后登出。

## 验收意见

在手机上挂了 3 小时没有被登出，通过。
