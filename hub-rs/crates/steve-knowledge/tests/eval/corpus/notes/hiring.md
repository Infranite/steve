# 后端工程师招聘

## 岗位要求

熟悉 Rust 或 Go 至少一门，有 SQLite / PostgreSQL 的实际使用经验，理解 HTTP、SSE、WebSocket。加分项：做过搜索、推荐或者 LLM 相关的产品。

## 面试流程

1. 简历筛选：李娜负责，两个工作日内给反馈。
2. 电话面试：30 分钟，聊过往项目。
3. 在线笔试：实现一个带过期时间的 LRU 缓存，限时 90 分钟。
4. 现场面试：两轮技术面加一轮文化面，同一天完成。
5. 发 offer 前做背景调查。

## 薪资范围

高级工程师年薪 45–60 万，另有期权。薪资范围不对外公开，只在发 offer 时沟通。

## 面试官注意事项

不问婚育、年龄、籍贯等与工作无关的问题。面试记录在面试结束当天写完，写清楚优点、顾虑和是否推荐。
