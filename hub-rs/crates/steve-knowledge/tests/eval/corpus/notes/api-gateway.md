# API 网关与限流

## 限流规则

对外 API 默认每个令牌每秒 100 个请求（100 rps），突发上限 200。用令牌桶算法实现：桶容量 200，每秒补充 100 个令牌。超过限制返回 HTTP 429，并在 `Retry-After` 头里告诉客户端多久后重试。

企业客户可以申请提高额度，Acme 目前是 300 rps。

## 鉴权

所有请求必须带 `Authorization: Bearer <token>`。令牌在控制台创建，可以设置过期时间和权限范围（只读 / 读写）。令牌泄露时在控制台吊销，30 秒内全网生效。

## 超时

网关到后端的超时是 30 秒；SSE 长连接不受这个限制，但每 15 秒发一次心跳注释行，防止中间代理断开空闲连接。
