# K8s 集群升级记录

把测试集群从 1.30 升到 1.32，生产集群下个月再升。

## 步骤

1. 先升级控制平面，一次只升一个小版本：1.30 → 1.31 → 1.32。
2. 每升一个版本，检查废弃的 API：用 `kubectl convert` 把旧的 manifest 转成新版本。
3. 节点按批次排空（drain）后升级，每批不超过 3 台，保证 PodDisruptionBudget 不被打破。
4. 升级 ingress 控制器和 CSI 驱动，它们对集群版本有要求。

## 遇到的问题

- 一个老的 CronJob 用了 `batch/v1beta1`，1.25 起就移除了，升级前没发现，导致定时任务没跑。以后升级前先跑一遍废弃 API 扫描。
- 节点排空时有个 Pod 没有设置 PDB，被一次性全部驱逐，服务中断了 2 分钟。
