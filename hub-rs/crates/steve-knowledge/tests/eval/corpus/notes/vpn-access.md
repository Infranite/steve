# 内网访问与 VPN

公司内网服务（监控面板、内部 Wiki、构建服务器）只能通过 WireGuard VPN 访问。

## 申请

在 IT 服务台提交“VPN 账号申请”，写明用途和需要访问的网段，直属主管审批后 IT 会发一个配置文件。配置文件里有私钥，不要转发给别人，也不要放进代码仓库。

## 使用

- macOS 和 iOS 装官方 WireGuard 客户端，导入配置文件即可。
- 连接后访问 `wiki.internal`、`grafana.internal` 等内部域名。
- 默认只路由内网网段，访问外网不走 VPN。

## 常见问题

连不上时先检查本机时间是否准确，再看客户端的握手时间；超过 3 分钟没有握手，多半是配置文件过期，重新申请即可。离职或换设备时要通知 IT 吊销旧的密钥。
